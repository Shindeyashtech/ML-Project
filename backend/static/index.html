How FaceFolio Works
01
Upload a Photo
Any photo with people. The backend saves it temporarily and passes it to the face detection pipeline.
02
MTCNN Face Detection
Multi-task Cascaded CNN detects all faces in the image and returns bounding boxes. Duplicate detections are filtered by cosine distance and IoU overlap.
03
512-D Embedding (FaceNet)
InceptionResNetV1 (pretrained on VGGFace2) converts each aligned face crop into a 512-dimensional embedding vector that encodes facial geometry.
04
Cosine Distance Matching
Each embedding is compared against the face_encodings.pickle database using cosine distance. A match below the threshold (default 0.6) identifies the person.
05
Label & Learn
Unknown faces are shown as crops. You type a name → the embedding + name are appended to the pickle database so future photos recognize this person.
06
Auto-Sort into Folders
The original photo is copied into sorted_photos/<name>/ for every person detected — both identified and newly labeled.
Common Issues & Fixes
❌ "Upload failed" / CORS error
The FastAPI server isn't running. Start it with: uvicorn main:app --reload --port 8000 and open http://localhost:8000
❌ No faces detected
Image may be too dark, low-res, or faces too small/angled. Run python debug_detect.py your_image.jpg to test detection directly.
❌ Wrong person identified
Cosine threshold may be too loose. Lower the threshold value in find_best_match() in main.py (try 0.45).
❌ "Original photo not found" on finalize
Server was restarted between scan and finalize — temp files and cache were cleared. Re-upload and label again.
❌ Frontend not loading
Make sure index.html, styles.css, and app.js are inside a static/ folder in the backend directory.
